# Code of Conduct

be normal.

## expected

- respect people in issues, PRs, and discussions
- argue about code, not about people
- no harassment, hate, or doxxing
- no spam, malware links, or scam "injectors"

## not ok

- insults, threats, or brigading
- posting private info
- pushing bypass / stealers / account stuff in this community space
- pretending someone else's work is only yours (see LICENSE credits)

## enforcement

maintainers can edit, lock, or ban when needed. if something crosses a line, open a private note via the security contact in SECURITY.md or mention @binx-ux on the repo.

## scope

applies to github issues, PRs, discussions, and other spaces tied to this repo.
