# Contributing

thanks for looking at the repo.

## what this project is

source / dll only. no injector, no bypass, no driver. PRs that add those get closed.

## before you open an issue

1. read the README
2. make sure you built Release x64 and are on a supported process
3. for Fortnite offsets: pull latest first. i (kyn) push FN offset updates after patches
4. for FiveM: broken scans / build offsets are on you unless you have a clear bug in the shared code

do **not** open issues asking for:
- injectors / loaders
- eac / anticheat bypass
- paid keys / remote auth panels
- "can you make it undetected"

## bug reports

use the Bug report template. include:
- game (Fortnite or FiveM) and roughly which build
- what you expected vs what happened
- steps if you have them

## feature requests

use the Feature request template. keep it realistic for a read-mostly internal menu dll.

## pull requests

1. fork, branch off `main`
2. keep changes small and readable
3. dont dump random paste code with no explanation
4. keep credits intact (`LICENSE`, `NOTICE`, README)
5. no Cursor / AI co-author trailers required or wanted on commits here. just your name

### FiveM PRs

welcome if they actually fix patterns or build tables. say which FiveM build you tested.

### Fortnite PRs

FN offsets are usually handled by kyn. if you send an offset PR, note the game version so it can be checked.

## code style

match what is already in the files. no giant comment banners. smallest change that works.

## license

by contributing you agree your changes ship under the same `LICENSE` as the rest of the repo, with credits kept.
