# Security

## what this repo is not

this is not a place to report game anticheat bypasses, or to request help dodging bans.

## reporting a real problem in this code

if you found something in **this repository** that could hurt users of the source itself (ex: the sample auth path doing something unsafe, a dependency issue), email or open a private security advisory on github if available.

contact: open a limited issue titled `security: ...` without dumping a full exploit chain, or message the repo owner on github (@binx-ux).

## please do not

- ask for eac bypass help
- drop malware
- report "i got banned" as a security issue

## disclosure

give a bit of time before posting full details publicly if it is an actual vulnerability in the repo tooling.
